# Aba PEDIDOS + Título Editável + Pagamento com Parcelas — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adicionar a aba PEDIDOS (orçamentos aprovados), campo de título de documento editável que sai no PDF, e seleção de parcelas de cartão de 1x a 24x via caixa de diálogo.

**Architecture:** Um pedido É um orçamento com `status = "aprovado"` — mesma tabela `quotes`, mesmo código. O formulário de `src/app/orcamento/page.tsx` vira um componente compartilhado `QuoteForm` com prop `mode: "orcamento" | "pedido"`; as páginas viram wrappers finos. O PDF lê o novo campo `doc_title`. Parcelas são gravadas em `payment_methods` como `cartao:N`.

**Tech Stack:** Next.js 16 (App Router, client components), React 19, TypeScript, Tailwind v4, Supabase (API routes em `src/app/api`).

**Spec:** `docs/superpowers/specs/2026-08-12-pedidos-design.md`

**Nota sobre testes:** o projeto não tem framework de testes (sem jest/vitest no `package.json`). Verificação de cada task = `npm run build` sem erros + checagem manual no navegador. Não adicionar framework de testes (fora de escopo).

**Nota sobre commits:** os passos de commit deste plano só devem ser executados após confirmação explícita do usuário.

export function paymentLabel(method: string): string {
  const legacy: Record<string, string> = {
    cheque: "Cheque",
    pix: "Depósito / PIX",
    boleto: "Boleto",
    cartao: "Cartão de crédito — parcelado em até 10x",
  };
  if (method.startsWith("cartao:")) {
    const n = parseInt(method.split(":")[1], 10);
    return n > 1 ? `Cartão de crédito — ${n}x` : "Cartão de crédito — à vista";
  }
  return legacy[method] || method;
}
```

function nextQuoteNumber(quotes: Quote[], prefix: string): string {
  const year = new Date().getFullYear();
  const nums = quotes
    .map((q) => {
      const m = q.number.match(new RegExp(`${prefix}-(\\d{4})-(\\d{3})`));
      return m && parseInt(m[1]) === year ? parseInt(m[2]) : 0;
    })
    .filter((n) => n > 0);
  const seq = nums.length ? Math.max(...nums) + 1 : 1;
  return `${prefix}-${year}-${String(seq).padStart(3, "0")}`;
}
```

  function addCardPayment() {
    const key = `cartao:${cardInstallments}`;
    setPaymentMethods((prev) => {
      const withoutLegacy = prev.filter((m) => m !== "cartao");
      return withoutLegacy.includes(key) ? withoutLegacy : [...withoutLegacy, key];

    setCardModalOpen(false);

    setPaymentMethods((prev) => prev.filter((m) => m !== method));
